# 按任务约束与不确定回答处理

## 决策与原因

- 基于 [OpenAI 的技能与提示词文章](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)，减少与当前任务无关的强制阅读和机械步骤，保留具体的安全、授权与记录要求。
- grilling 遇到无法回答的问题时，降低抽象程度，使用情境、比较、反例或可选体验。间接答案只形成待验证线索，分别记录明确决定、暂定推断和未决问题；不把喜好相关性当作确定偏好。
- 访谈以当前范围内的重要决定足以支持下一步为结束标准。允许无偏好、明确暂缓和授权范围内的默认选择；反复追问不能代替证据或同意。事实查询仅在有独立工作且并行有收益时委派。
- grill-me 保持调用共享 grilling 正文，grill-with-docs 同样继承新流程，并明确不把暂定推断写成已接受的 ADR 或确定术语。
- Cairn 模板按任务需要读取 ROADMAP、LOG 与专题；完成检查在实质性进展的最终交付前触发。入口直接排除解释、只读审视、进度播报、等待和无实质进展，参考文档保留具体记录矩阵。
- 普通 Git 跟踪文件的干净基线局部编辑无需额外副本。强制导入、冲突覆盖或 Git 无法恢复原状态时仍须备份；备份不授权覆盖他人的工作。
