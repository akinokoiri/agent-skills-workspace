# Task Checkpoint

维护 `04_文档/进行中任务.md`，让工作状态随同步目录跨设备、跨会话存活。文件存在则读写，不存在则创建。

## 收尾（保存状态）

1. 逐段核对当前对话与工作区文件，只写事实。
2. 覆盖写入 `04_文档/进行中任务.md`，保持五段模板：
   - 任务：当前在做什么，一句话
   - 进度：已完成 / 进行中
   - 下一步：下个会话要做的第一个动作
   - 阻塞：卡住的事项，没有则写"无"
   - 本轮结论：这轮的关键判断，一行以内
3. 完成标准：五段全部填写，每段都反映真实状态。

## 开工（恢复状态）

1. 读取 `04_文档/进行中任务.md`；文件不存在则简报"无记录"。
2. 向用户简报：任务、进度、下一步、阻塞。
3. 得到用户确认后，从"下一步"继续。
4. 完成标准：简报覆盖四段，且已获得继续执行的确认。
