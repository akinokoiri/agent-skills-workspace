# 指标与实际场景

用能够反映本次故障的结果判断修复。低层检查适合定位环节；它能支持什么结论，取决于与用户目标的实际关系。

| 当前问题 | 有区分力的观察 |
|---|---|
| 页面卡顿 | HTTP 各阶段耗时与浏览器实际加载表现，用于区分传输、服务响应和渲染问题。 |
| 接口变慢 | 触发问题的请求大小、并发条件与耗时分布，用于定位传输、处理或竞争开销。 |
| 查询或存储卡住 | 实际查询的数据规模、执行计划与等待状态，用于区分执行成本和锁等待。 |
| 文件写入失败 | 在目标路径复现写入，查看权限、挂载状态与实际错误。 |

只补与当前故障机制相关的环境差异。若某个无法取得的条件妨碍结果判定，说明缺少的具体证据及其影响，继续可完成的工作。
